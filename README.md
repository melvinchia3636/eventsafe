# EventSafe

Monorepo for the EventSafe app.

## Structure

- `client/` — React + TypeScript + Vite + Tailwind CSS
- `server/` — NestJS API

## Getting started

Install dependencies from the repo root:

```bash
bun install
```

Run the client:

```bash
bun run dev:client
```

Run the server:

```bash
bun run dev:server
```

The client dev server starts on http://localhost:5173 and the API on http://localhost:3000.
